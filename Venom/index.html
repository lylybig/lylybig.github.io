Venom

A PyTorch Generative Modeling Toolkit

Venom collects readable MNIST-first implementations of diffusion models, score/SDE methods, flow matching, one-step generators, normalizing flows, VAEs, GANs, and energy-based models under one research scaffold.

Liang Yan
Allen School of CSE, University of Washington
Code README Notebook

Project Overview

Venom is designed for studying families of generative models side by side. Each family has a dedicated subpackage, training entrypoint, sampling entrypoint, checkpoint layout, and small Python API. 

pip install -e .
python train_diffusion.py --variant ddpm --epochs 5
python sample_diffusion.py --checkpoint runs/mnist_diffusion/ddpm/model_005.pt
